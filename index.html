How to work with Claude Code

01

Make it Ask Questions

Have Claude ask targeted questions to clarify precise requirements and goals before initiating work.

02

Ask it to Explore

Prompt it to explore codebases, internet sources, tools, and skills to gather comprehensive contextual insights.

03

Create a Plan

Direct it to formulate a structured, step-by-step action plan before making any code modifications.

04

Execute Plan

Command it to execute the planned architecture and implement code updates automatically.

05

Ask it to Test

Instruct it to create and run test suites, analyzing output to confirm correctness and prevent regressions.

Core Primitives

T

Tool

A function written in Python, TypeScript, etc., connected via the Model Context Protocol (MCP).

S

Skill

A specialized set of functions bundled with a prompt that describes precisely how to leverage them.

A

Subagent

A specialized, autonomous agent capable of utilizing various tools and skills to accomplish complex tasks.

Tools & Skills Ecosystem

Built-in Tools Docs

  • Core: Bash, Cron, File CRUD operations, Find
  • Search: Integrated WebSearch capabilities
  • Language Support: LSP integration (requires installation)

Custom Tools Docs

Connect custom tools to the CLI using MCP. Tool Search is enabled by default for seamless scaling. Strict permissions can be configured for all tools.

Built-in Skills Docs

  • /code-review, /debug - Code analysis
  • /deep-research <question> - Comprehensive web search
  • /design [brief] - Draft detailed UI mockups
  • /run, /verify - Execute and validate your application
  • /simplify [target] - Refactor and simplify code
  • /slides [brief] - Generate presentations

Custom Skills Docs

Custom skills operate securely and only gain access to parent conversations if explicitly forked.

Powerful Subagents Docs

Run seamlessly in the background or foreground.

Enforce strict permissions restricting access to specific tools and skills.

Maintain distinct memory at either the user or project level.

Access parent context exclusively when explicitly forked.

Safely modify code in an isolated, separate worktree.

Capable of recursively spawning their own subagents.

Essential Commands Docs

/usage
View token costs for current session and monthly aggregates.
/memory
List active memory files loaded in the current session.
/context
Analyze real-time context consumption details.
/rewind
Revert conversation and codebase to a previous checkpoint.
/resume
Restore and continue the previous conversation session.
/loop
Execute continuous tasks at defined intervals.
/branch
Fork the current conversation into a pristine new session.
/batch
Deploy multiple subagents to process task lists in parallel.
/output-style
Toggle modes: Proactive, Concise, Explanatory, or Learning.
